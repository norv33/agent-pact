How it works

  1. Create — an Agent ID holder writes a commitment with a deadline (max 30 days). They automatically join their own pact.
  2. Join — other Agent ID holders join before the deadline.
  3. Resolve — after the deadline, each participant marks their own result: kept or broken. One report per person, and it cannot be changed.

Agent ID is a non-transferable NFT, so one person holds at most one Agent ID — one wallet, one voice, one resolution per pact. AgentPact never asks for your seed phrase, private key, or pairing code. Every transaction is confirmed by you in your own wallet.
